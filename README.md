# CipherDNS

Egy modern, Python-alapú asztali alkalmazás a titkosított DNS (DNS over HTTPS - DoH) profilok gyors és egyszerű kezelésére Windows rendszereken.

## Tervezett funkciók
* TOP 5 biztonságos és gyors DNS kiszolgáló (Quad9, Cloudflare, stb.)
* 1-kattintásos beállítás és titkosítás
* Hálózati adapterek automatikus felismerése
* Modern, "Dark Mode" felhasználói felület
